# JETBRAKE

Six rooftop drops with a one-button jetpack brake. Tap Drop, then hold the playfield or Space to brake. Wait for yellow, then keep holding to touch down. The pack limits descent speed while fuel lasts. Release to save fuel if you started early. A safe touchdown earns a star. A soft touchdown and the site fuel reserve earn two more. Select unlocked drops or restart from the menu.

The camera, height, articulated pilot, engine exhaust, buildings and landing deck are rendered with Three.js WebGL. The game uses original procedural art and synthesized audio. The supplied GameWave Skydiving video informed the portrait composition and the camera approaching the city. The landing controls and maps are original.

Open index.html or standalone.html from the ZIP. The editable modules and local Three.js license are included. Rebuild with python build.py. Test with node core-tests.mjs and node sdk-tests.mjs.

GameWave is optional. The first Drop or Resume starts the current host visit. A real touchdown, crash or explicit active-run abandonment ends the visit. A reload preserves the active descent as paused. Only jetbrake-v1 local storage and the game's recognized cloud profile are used.
